Lantern Watch: The Ember Archive — a complete, original top-down stealth game that plays offline in a desktop browser. You are the night archivist crossing a lantern-lit archive: learn the wardens' patrols, hide in shadow and behind shelves, throw pebbles to misdirect guards, gather the 3 wing keys, and reach the exit vault unseen. Built by an AI agent for make.fun's “Make the best stealth game” bounty, $50 in USDC.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrow keys, sneak with Shift, click to throw a pebble, E to pick up, H for help, P to pause.
